# Quickstart: Whole-Film Continuity Wizard

## Zero-call developer walkthrough

1. Use an active project whose three-shot Storyboard and semantic asset manifest are approved.
2. Open `全片一致性`, create deterministic suggestions, and confirm environment, character,
   product/prop, camera, and style policies.
3. Introduce one contradictory prop state across an internal boundary. Verify the timeline names the
   shot, subject, conflict, and business action; resolve it by inheriting or declaring the change.
4. Approve the blocker-free profile and preview `fake-keyframe-v1`. Confirm four targets, four-call
   maximum, zero cost, zero external calls, expiry, and no-retry notice.
5. Authorize and run Fake once. Approve all four retained keyframes from the contact sheet.
6. Preview H3 without submitting. Verify `普通参考`, start keyframe in Scene, end keyframe marked soft
   QA target, maximum three video calls, and hard-lock requests blocked.
7. With local technically valid fixture videos, create a draft containing warnings and verify formal
   assembly still requires Human PASS.

## Verification commands

Run project formatting, lint, type checking, focused/full Vitest suites, Prisma validation and
migration rehearsal, production build, and browser QA. Confirm the test call ledger reports zero
Codex Manager image, AI QA, H3, or other external generation calls.

## LIVE boundary

Do not enable or run LIVE image/video acceptance as part of implementation. A later real three-shot
test must first show current model snapshot, capability facts, exact image/video/AI-QA call ceilings,
current cost estimate, expiration, and no-retry policy, then obtain a new action-time owner approval.
